# -M20261509

## 프로젝트 소개

이 프로젝트는 잎의 맥 구조를 기준으로 학습한 AI 모델을 사용해,
잎이 `그물맥`인지 `나란히맥`인지 판별하고, 이를 바탕으로
`쌍떡잎` 또는 `외떡잎`으로 분류하는 웹 애플리케이션입니다.

즉, 단순히 잎의 전체 모양만 보지 않고,
잎맥의 배열 패턴을 기준으로 분류하도록 학습시킨 모델입니다.

- `그물맥` → `쌍떡잎`
- `나란히맥` → `외떡잎`

사용자는 사진을 업로드하면 다음 정보를 확인할 수 있습니다.

- 예측 결과와 확률 막대그래프
- 각 클래스별 확률 표시
- 확률이 낮은 경우 불명확 상태 메시지 출력
- 혼동행렬(Confusion Matrix)
- 오답사진모음(오분류된 예시 이미지)

## 기능 구성

### 1) 이미지 업로드 및 예측
- 사용자가 잎 사진을 업로드하면 미리보기 표시
- Teachable Machine 기반 모델이 이미지를 분석
- 잎맥의 구조를 바탕으로 예측 수행
- 각 클래스에 대한 확률 값을 계산
- 가장 높은 확률을 기준으로 결과 출력
- 확률이 0.7 미만이면 "특징이 모호하여 잘 모르겠어요!" 메시지 출력

### 2) 혼동행렬
- 실제값과 예측값을 기준으로 분류 결과를 표로 시각화
- 현재 데모에서는 예시 값으로 구성된 혼동행렬을 사용하고 있으며, 아래는 예시 데이터입니다.
  - 쌍떡잎 실제 / 쌍떡잎 예측: 9
  - 쌍떡잎 실제 / 외떡잎 예측: 1
  - 외떡잎 실제 / 쌍떡잎 예측: 0
  - 외떡잎 실제 / 외떡잎 예측: 10
- 실제 프로젝트 코드에서는 `confusionMatrix` 배열을 직접 정의해 사용합니다.

### 3) 오답사진모음
- 모델이 잘못 예측한 이미지들을 카드 형태로 표시
- 각 카드 아래에 `실제값 → 예측값` 형식으로 설명 추가
- 잘못 분류된 사례를 직접 확인하며 모델 성능을 이해할 수 있도록 구성
- 현재 예시 데이터는 `assets/miclassified/wrong_01.png` 하나를 사용하도록 구성되어 있습니다.

## 동작 방식

1. 사용자가 잎 사진 업로드
2. 모델 로딩 상태 확인
3. 이미지 로드 완료 후 `model.predict()` 실행
4. 잎맥 패턴에 따른 각 클래스별 확률 계산
5. 가장 높은 확률의 클래스를 결과로 표시
6. 결과와 함께 혼동행렬, 오답사진모음 렌더링

## 모델 학습 기준

이 프로젝트는 단순한 외형 분류가 아니라,
잎맥의 형태를 학습 데이터로 활용해 분류하도록 설계되었습니다.

- `그물맥`: 잎맥이 그물처럼 엮여 있는 구조
- `나란히맥`: 잎맥이 평행하게 나 있는 구조

이 두 가지 기준으로 모델이 다음을 구분하도록 학습됩니다.

- 그물맥 → 쌍떡잎
- 나란히맥 → 외떡잎

## 수정 이력

### 1) 이미지가 잘리는 문제 수정
처음에는 오답사진 카드에서 이미지가 잘려서 보였는데, 이는 `object-fit: cover` 설정 때문에 발생한 문제였습니다.

이미지를 전체적으로 보이도록 하기 위해 아래와 같이 수정했습니다.

```css
.wrong-card img {
    width: 100%;
    height: 180px;
    object-fit: contain;
    object-position: center;
    border-radius: 8px;
    display: block;
    background: #eef2f7;
}
```

이 변경으로 이미지가 카드 내부에서 잘리지 않고 전체가 보이게 되었습니다.

### 2) 카드 레이아웃 안정화
- 이미지 높이를 고정하여 레이아웃 정렬 유지
- 이미지가 없거나 로드 실패 시 대체 안내 UI 표시
- 카드 배경 및 여백 조정으로 깔끔한 레이아웃 구성

### 3) UX 개선
- 업로드 버튼과 결과 표시가 자연스럽게 보이도록 정리
- 예측 확률 표시가 가독성 있게 개선
- 불명확한 결과에 대한 안내 메시지 추가
