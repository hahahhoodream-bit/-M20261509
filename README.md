## 프로젝트 개요

이 프로젝트는 잎 사진을 업로드하면, Teachable Machine 기반 AI 모델이 잎의 형태를 판별해
"쌍떡잎" 또는 "외떡잎" 중 하나를 예측하는 웹 애플리케이션입니다.

사용자는 이미지를 업로드하면 다음 내용을 확인할 수 있습니다.

- 예측 확률 막대그래프
- 결과 클래스 표시
- 확률이 낮을 경우 "특징이 모호하여 잘 모르겠어요!" 메시지 표시
- 혼동행렬(Confusion Matrix) 시각화
- 오답사진모음(잘못 분류된 예시 이미지) 표시

## 화면 구성

### 1) 메인 업로드 영역
- 사진 업로드 버튼 제공
- 업로드한 이미지 미리보기 표시
- AI 모델 로딩 상태 표시
- 예측 결과 및 확률 프로그레스 바 표시

### 2) 혼동행렬
- 실제값과 예측값을 기준으로 분류 결과를 테이블로 표시
- 예시 값:
  - 쌍떡잎 실제 / 쌍떡잎 예측: 9
  - 쌍떡잎 실제 / 외떡잎 예측: 1
  - 외떡잎 실제 / 쌍떡잎 예측: 0
  - 외떡잎 실제 / 외떡잎 예측: 10

### 3) 오답사진모음
- 잘못 분류된 샘플 이미지를 카드 형식으로 보여줌
- 각각의 이미지 아래에 "실제 레이블 → 예측 레이블" 형식으로 설명 추가

## 동작 방식

1. 사용자가 사진 업로드
2. 모델 로드 완료 여부 확인
3. 이미지가 로드되면 `model.predict()` 실행
4. 각 클래스의 확률 계산
5. 가장 높은 확률을 기준으로 결과 표시
6. 가장 높은 확률이 0.7 미만이면 불명확 상태로 처리
7. 혼동행렬과 오답사진모음 렌더링

### UX 개선 사항
다음 항목은 대화 과정을 통해 수정 및 반영된 부분입니다.

- 오답 사진이 카드 안에서 잘려 보이는 문제 수정
- `object-fit: cover`에서 `object-fit: contain`으로 변경
- 이미지 높이를 고정해서 카드 레이아웃 안정화
- 이미지 로드 실패 시 대체 메시지 표시 추가
- `.no-image` 블록을 활용해 빈 이미지 상태를 자연스럽게 처리

## 수정 이력 요약

### 1) 잘린 이미지 문제 해결
처음에는 오답 사진이 카드 영역을 꽉 채우려 하면서 일부가 잘려 보였습니다. 이는 `object-fit: cover` 때문에 발생한 문제였고, 전체 이미지를 자연스럽게 보이도록 아래처럼 수정했습니다.

```css
.wrong-card img {
    width: 100%;
    height: 180px;
    object-fit: contain;
    object-position: center;
    border-radius: 8px;
    display: block;
    background: #eef2f7;
}
```

### 2) 이미지 카드 레이아웃 보완
- 카드 높이를 일정하게 유지
- 이미지가 가운데 정렬되도록 설정
- 이미지가 없거나 로드에 실패해도 대체 안내가 보이도록 보완
